# release/ (generated)

Everything in `release/artifact/` is generated by `bash deploy/pack.sh` and committed, so the production box only copies it (root `Dockerfile`, `DEPLOY.md`) and never runs npm. Don't edit it by hand: change `server/`, `app/` or `landing/` and run the pack script again.

- `server.mjs`: the server, the engine and the npm dependencies bundled into one file.
- `web/`: the landing page at `/` and the Expo web export at `/app/`.
- `samples/`: the licensed eval photos and their attribution (the server serves only the six samples).
- `cache/assessments/`: the recorded live results for the samples.
